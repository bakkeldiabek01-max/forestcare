# 🌲 ForestCare — OYAN

**OYAN командасы · Future Edition**

ForestCare — орман өртін ерте анықтау жүйесі. Raspberry Pi 4-ке қосылған екі сенсор ормандағы қауіпті өзгерістерді үздіксіз бақылайды:

| Сенсор | Не өлшейді | Қосылуы |
|---|---|---|
| **BME280** | Температура, ылғалдылық, атмосфералық қысым | I2C (3.3V, SDA, SCL) |
| **MQ-2** | Түтін және жанғыш газдар | DO → GPIO17 (кернеу бөлгіш арқылы) |

## Қауіп деңгейі

| Белгі | Шарт | Ұпай |
|---|---|---|
| 🌡 Температура | > 30°C / > 40°C | +1 / +2 |
| 💧 Ылғалдылық | < 35% / < 20% | +1 / +2 |
| 💨 Түтін | MQ-2 сигнал берсе | +4 |

🟢 0–1 **ҚАЛЫПТЫ** · 🟡 2–3 **НАЗАР** · 🟠 4–5 **ҚАУІПТІ** · 🔴 6+ **ӨРТ ҚАУПІ!**

## Файлдар

- `index.html` — жоба сайты және тірі бақылау тақтасы
- `config.js` — сайт деректерді оқитын Firebase мекенжайы
- `oyan.py` — Raspberry Pi-да жұмыс істейтін бағдарлама (өлшеу, CSV журнал, веб-сервер, Firebase-ке жіберу, Telegram-ескерту)
- `config.example.json` — Pi-дағы `~/oyan/config.json` үлгісі (Firebase мекенжайы, Telegram токені)
